Aldrich - Carrion and Plague 1.0.0 - Going Medieval (tested on 1.1.19)
by Aldrich

- Unburied bodies bring rat swarms, larger and more often.
- Each rat bite that lands: 35% chance of plague fever.
- The plague spreads between settlers standing close together.
- Survivors are immune for life.
- Plague doctor mask and waxed coat lower the chance; wear both.
- Cat statue: cats keep coming back only while one stands (3 per statue).
English and Spanish texts.

REQUIREMENTS
BepInEx 5 (x64) installed in the Going Medieval folder.

INSTALL
With Vortex: install it like any other mod.
By hand: copy the BepInEx folder of this archive into the Going Medieval
folder (where "Going Medieval.exe" is), so you end up with
  Going Medieval\BepInEx\plugins\AldrichCarrionAndPlague\Aldrich.CarrionAndPlague.dll

On the first launch the mod copies its data to
  Documents\Foxy Voxel\Going Medieval\Mods\CarrionAndPlague
which is where the game reads mods from. If it is not active in the game's
Mods menu, enable "Aldrich - Carrion and Plague" there once.

UNINSTALL
Delete the AldrichCarrionAndPlague folder from BepInEx\plugins and the
CarrionAndPlague folder from Documents\Foxy Voxel\Going Medieval\Mods.
Things already built or spawned with it will be lost in saves that use them.

LOG
If something goes wrong: Going Medieval\BepInEx\LogOutput.log, lines
starting with [data] and "Aldrich - Carrion and Plague".
