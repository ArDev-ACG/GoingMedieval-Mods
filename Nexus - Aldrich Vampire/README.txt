Aldrich - Vampire Court 1.0.0 - Going Medieval (tested on 1.1.19)
by Aldrich

- Vampire perk (advanced character creation): little sleep, little food,
  hits harder, heals faster, burns in the sun, does not feel the cold.
- Thirst and bite; bitten settlers become thralls.
- Ghoul perk for the servants.
- The Count role: four ranks earned by killing, the last one is Dracula.
- Blood draughts, blood well, blood altar.
- A court of furniture, each piece behind its research.
- The Crimson Vigil celebration.
English and Spanish texts.

REQUIREMENTS
BepInEx 5 (x64) installed in the Going Medieval folder.

INSTALL
With Vortex: install it like any other mod.
By hand: copy the BepInEx folder of this archive into the Going Medieval
folder (where "Going Medieval.exe" is), so you end up with
  Going Medieval\BepInEx\plugins\AldrichVampireCourt\Aldrich.VampireCourt.dll

On the first launch the mod copies its data to
  Documents\Foxy Voxel\Going Medieval\Mods\VampireCourt
which is where the game reads mods from. If it is not active in the game's
Mods menu, enable "Aldrich - Vampire Court" there once.

UNINSTALL
Delete the AldrichVampireCourt folder from BepInEx\plugins and the
VampireCourt folder from Documents\Foxy Voxel\Going Medieval\Mods.
Things already built or spawned with it will be lost in saves that use them.

LOG
If something goes wrong: Going Medieval\BepInEx\LogOutput.log, lines
starting with [data] and "Aldrich - Vampire Court".
