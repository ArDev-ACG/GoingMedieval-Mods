Aldrich - Undead Horde 1.0.0 - Going Medieval (tested on 1.1.19)
by Aldrich

- The Risen: a new hostile faction that never surrenders or retreats.
- No armour, no weapons: claws that tear doors and leave festering wounds.
- Three kinds: risen, brutes and lurkers.
- The Risen and other raiders fight each other on sight.
- 35% of raids from other hostile factions are taken over by the horde
  (configurable in BepInEx\config\aldrich.undead_horde.cfg).
English and Spanish texts.

REQUIREMENTS
BepInEx 5 (x64) installed in the Going Medieval folder.

INSTALL
With Vortex: install it like any other mod.
By hand: copy the BepInEx folder of this archive into the Going Medieval
folder (where "Going Medieval.exe" is), so you end up with
  Going Medieval\BepInEx\plugins\AldrichUndeadHorde\Aldrich.UndeadHorde.dll

On the first launch the mod copies its data to
  Documents\Foxy Voxel\Going Medieval\Mods\UndeadHorde
which is where the game reads mods from. If it is not active in the game's
Mods menu, enable "Aldrich - Undead Horde" there once.

UNINSTALL
Delete the AldrichUndeadHorde folder from BepInEx\plugins and the
UndeadHorde folder from Documents\Foxy Voxel\Going Medieval\Mods.
Things already built or spawned with it will be lost in saves that use them.

LOG
If something goes wrong: Going Medieval\BepInEx\LogOutput.log, lines
starting with [data] and "Aldrich - Undead Horde".
