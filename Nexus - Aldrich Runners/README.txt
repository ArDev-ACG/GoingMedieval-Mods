Aldrich - The Runner 1.0.0 - Going Medieval (tested on 1.1.19)
by Aldrich

- The Runner: fast pack hunter, never flees, climbs walls.
- Acid blood that burns and splashes; a tail that lashes.
- Eggs that hatch Spider Aliens, which leap onto faces.
- Settlers panic near Runners.
- Own carcasses: carapace and bones, no meat.
Settings in BepInEx\config\aldrich.xenomorph_runner.cfg.
English and Spanish texts.

REQUIREMENTS
BepInEx 5 (x64) installed in the Going Medieval folder.

INSTALL
With Vortex: install it like any other mod.
By hand: copy the BepInEx folder of this archive into the Going Medieval
folder (where "Going Medieval.exe" is), so you end up with
  Going Medieval\BepInEx\plugins\AldrichXenomorphRunner\Aldrich.XenomorphRunner.dll

On the first launch the mod copies its data to
  Documents\Foxy Voxel\Going Medieval\Mods\XenomorphRunner
which is where the game reads mods from. If it is not active in the game's
Mods menu, enable "Aldrich - The Runner" there once.

UNINSTALL
Delete the AldrichXenomorphRunner folder from BepInEx\plugins and the
XenomorphRunner folder from Documents\Foxy Voxel\Going Medieval\Mods.
Things already built or spawned with it will be lost in saves that use them.

LOG
If something goes wrong: Going Medieval\BepInEx\LogOutput.log, lines
starting with [data] and "Aldrich - The Runner".
